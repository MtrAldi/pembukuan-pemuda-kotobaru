# 💰 Aplikasi Pembukuan Pemuda Kotobaru

Aplikasi web sederhana untuk mencatat dan mengelola keuangan/kas organisasi pemuda Kotobaru berbasis Streamlit.

## ✨ Fitur
- **Dashboard Ringkasan:** Cek Saldo Total, Total Pemasukan, dan Total Pengeluaran secara *real-time*.
- **Input Transaksi Cepat:** Form input untuk mencatat kas masuk (iuran, donasi, sumbangan) dan kas keluar (kegiatan, operasional).
- **Laporan & Riwayat:** Filter transaksi dan opsi unduh/download laporan dalam bentuk file CSV/Excel.

---

## 🚀 Panduan Deploy ke GitHub & Streamlit Cloud (Gratis)

### 1. Push Repository ke GitHub
Buka terminal dan jalankan perintah berikut di folder proyek ini:

```bash
git init
git add .
git commit -m "Initial commit aplikasi pembukuan pemuda kotobaru"
git branch -M main
git remote add origin https://github.com/<username-github-anda>/<nama-repo>.git
git push -u origin main
```

### 2. Deploy ke Streamlit Community Cloud
1. Kunjungi [share.streamlit.io](https://share.streamlit.io/) dan login dengan akun GitHub Anda.
2. Klik tombol **New app**.
3. Pilih repository yang sudah Anda buat, branch `main`, dan set file utama ke `app.py`.
4. Klik **Deploy!**

Aplikasi akan online dan siap diakses melalui browser oleh seluruh pengurus organisasi!
